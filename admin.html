Device limits

Issues are turned off for the repository. Device limits and feedback both use issues, so they cannot work: a key limited to a number of devices cannot be activated. On GitHub: the repository → Settings → General → Features → tick Issues. Then tap ↻ at the top.

To limit a key to a number of devices, the app records each activation as an issue in the repository. For that it needs a second GitHub token that can only handle issues. It is stored in the repository encrypted, readable only by licensed apps. The same token carries feedback and last online.
